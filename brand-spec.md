# Ver Mirandela — design system

## Design read

- Artifact: public-data explorer and civic dashboard
- Audience: residents, journalists, researchers, municipal stakeholders
- Visual language: Portuguese editorial civic modernism
- Mode: greenfield
- Visual variance: 6/10
- Motion intensity: 3/10
- Information density: 7/10
- Asset dependence: 2/10
- Brand fidelity: independent identity; no municipal branding copied

## Decisions

- Palette: deep municipal green `#173c32`, warm paper `#f1eee5`, ink `#17211e`, gold `#e0a44f`, terracotta `#b85e43`
- Typography: Iowan Old Style/Baskerville/Georgia for display contrast; Avenir/system sans-serif for data and UI
- Spacing: 8px base grid
- Radius: restrained 10–14px panels; pills only for status
- Shadow: one soft low-elevation shadow, with borders doing most structural work
- Motion: 180–260ms state transitions; disabled under reduced-motion preference
- Asset policy: independent letter seal; no copied municipal coat of arms or Open Lousada assets
